# W3-D · Matching accuracy — handoff (wave 3)

## Summary
The accuracy tooling exists and is validated end to end; the real-session run is the one pending step because no consented session was nominated this wave. `scripts/accuracy.mjs` (plain Node, no dependencies) takes a session's D1 export (`photos`, `faces`, optional `photo_links` and `photo_appearances`) plus crew labels (`photo_id,surfer_id`, `-` for none) and reports precision / recall / F1 of the **shipped** `/api/match` ranking at every threshold from 0.55 to 0.70 in 0.01 steps, per surfer, with the score distribution, zero-face counts, label-hygiene checks (bystanders, missing detections, suspect queries) and the HOG person-detector numbers — including whether HOG's person box actually contains a detected face, which `faces.bbox_json` and `photo_appearances.bbox_json` make possible from the export alone. The ranking is replicated from `worker.js` (`similarity()` and the `/api/match` block that builds the `scores` Map, filters on `MATCH_THRESHOLD`, caps at 80 and adds `extensions` from confirmed `photo_links` at `CONFIRMED_LINK_SCORE_DISCOUNT`; line numbers are omitted because `worker.js` is being edited concurrently) because those functions are not exported; `--selftest` imports the real `worker.js` handler with a mocked env and requires identical photo order and scores on the bundled fixture at four thresholds, one of them an exact score so `>=` versus `>` is caught (mutating either the link discount or the comparison makes the self-test fail — verified). `face-api/accuracy_fixture.py` builds the inputs through a running face service: `extract` for a folder of originals, `synthetic` for the validation set. The synthetic set (128 photos, 135 real 512-d `buffalo_l` embeddings, 7 identities from InsightFace's bundled test images with 17 augmentations each, zero-face photos with confirmed burst links, two real surf photos as negatives) produces a believable curve — recall 97 % → 84 % across the band at 100 % precision, because seven strangers from one photo have no lookalikes — which `docs/accuracy.md` reports clearly labelled synthetic, together with the HOG breakdown (right-person recall 12 % on those framings; HOG never found a small pasted person and mostly misses head-and-shoulders crops) and the confidence-gate what-if. Recommendation: **`MATCH_THRESHOLD` unchanged at 0.62 until the real run**; the tool's own rule needs 20 queries, precision ≥ 0.90 and an F1 gain of 0.02 before it suggests a move. `face-api/main.py` is untouched (no debug endpoint was needed). `npm run check` ok, `npm test` 156/156 at the final run; `npm run e2e` 110 passed / 21 failed, all failures in W3-A/W3-C screens changing concurrently (details in "How to verify").
